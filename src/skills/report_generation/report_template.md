## Instruções para Preenchimento

**Seção 1 - Resumo Executivo:**
- Use datas em formato DD/MM/YYYY
- Status: 🟢 Positivo / 🟡 Neutro / 🔴 Negativo
- Valores sempre com 2 casas decimais

**Seção 2 - Análise por Categoria:**
- Ordenar categorias por valor (maior → menor)
- Percentuais com 1 casa decimal
- Incluir linha de TOTAL no final
- Top 3 sempre as maiores despesas

**Seção 3 - Padrões:**
- Mínimo 2, máximo 5 padrões
- Sempre com dados concretos (valores, quantidades, frequências)

**Seção 4 - Riscos:**
- Emoji: 🟢 Baixo / 🟡 Médio / 🔴 Alto
- Alertas sempre com impacto quantificado
- Mínimo 1, máximo 5 alertas

**Seção 5 - Recomendações:**
- Mínimo 3, máximo 5 recomendações
- Cada uma deve ser SMART (Específica, Mensurável, Atingível, Relevante, Temporal)
- Priorizar por impacto (maior impacto primeiro)
